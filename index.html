Оборудование для ремонта электромашин мощностью до 100 кВт

ООО «ELMASH» предлагает оборудование для ремонта электрических машин до 100 кВТ. Наш завод занимается изготовлением различного оборудования для ремонта электрических машин: электрокалорифер, обжиговая печь, станки для удаления обмоток, кантователь статоров, камера обдува статоров, намоточные станки для трансформаторов, камера окрасочная, станки для обрезки лобовых частей электродвигателя и многое другое. Изготовление оборудования производится на нашем собственном производстве, поэтому мы гарантируем качество всей выпускаемой продукции.

Мы производим:

Электрокалорифер РИФЖ 681813.006

Установка для сушки и подогрева обмоток электрических машин горячим воздухом.

Установка обжиговая РИФЖ 681591.015

Печь для термической деструкции изоляции старых обмоток статоров с дожигом газов.

Установка для индукционного нагрева подшипников РИФЖ 681591.011

Быстрый индукционный нагрев подшипников и муфт с контролем температуры и авторазмагничиванием.

Кантователь статоров электродвигателей 7-9 габаритов РИФЖ 481447.008

Гидравлический кантователь для безопасного поворота статоров на 360° при укладке обмотки.

Станок намоточный быстроходный универсальный РИФЖ 045119.009 с частотным преобразователем

Высокоскоростная намотка обмоток с плавным регулированием скорости и электронным счетчиком.
